# Programming Assignment 3 — Hospital Quality (Johns Hopkins R Programming)

This repository contains my implementation of **Programming Assignment 3: Hospital Quality**  
from the [Johns Hopkins University *R Programming* course](https://www.coursera.org/learn/r-programming),  
part of the **Data Science Specialization**.

---

## 🩺 Project Overview
This assignment explores hospital performance using data from the **Hospital Compare** database,  
maintained by the U.S. Department of Health and Human Services (HHS).  

The project focuses on identifying and ranking hospitals based on **30-day mortality rates**  
for the following conditions:

- **Heart Attack**
- **Heart Failure**
- **Pneumonia**

It demonstrates proficiency with:
- Reading and cleaning real-world CSV data  
- Handling missing values and coercing character data to numeric  
- Sorting and ranking using base R  
- Defensive programming and reproducibility
